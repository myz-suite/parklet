## 14:40 CST — 修复 `extract --article` 返回 HTML 而非 Markdown

用户对比 `defuddle.md/<url>` 与 `plt extract --article`：后者输出原始 HTML `<div>…</div>`。

- **根因**：扩展导入核心包 `defuddle`，其不含 markdown 转换器，`markdown: true` 被静默忽略（隔离验证：核心包 markdown:true 仍返回 HTML / 无 contentMarkdown；`defuddle/full` 才带 turndown）。
- **修复**：改导入 `defuddle/full`（`markdown:true` 生效）；article 结果新增 `description`/`domain`/`language`/`url` 字段（protocol + extension）；CLI 以 YAML frontmatter 打印 + Markdown 正文。
- **代价**：`content.js` ≈535KB → ≈1.1MB（未 minify；完整包含 turndown + 数学转换）。
- **验证**：mock `/article` 加粗体/链接/描述；E2E article 用例断言 `**bold**`、`[link](…)`、无 `<p>`、frontmatter `title:`/`url:`。全量 typecheck/test（136）/build/lint 绿；`pnpm test:e2e` 14 passed。

### 平滑工作流修复（server 退出 + 扩展状态 badge）

1. **Ctrl+C 不退出 + MaxListeners**：根因 `httpServer.close()` 等长连接、`ExtensionHub.close()` 未终止活跃 WS，导致回调不触发、进程不退出；反复 Ctrl+C 累积 `close` 监听 → warning。修复：`hub.close()` 发 `close(1001)` 并延迟 terminate + 超时；`closeAllConnections()`；`plt serve` shutdown 加重入保护与 2s 兜底。实测 SIGINT → exit 0 / 59ms / 客户端 close 1001，无 warning；单测 `ws/server.test.ts`。
2. **扩展连接状态**：新增 `status.ts` 状态机 + action badge（绿=connected/红=disconnected/橙=unconfigured|auth_failed）+ `storage.session` 持久化 + SW 重启 `restoreState()`；token 被拒（4401/4400）停止自动重连；popup 显示引导 + Retry。E2E 4 例 badge 状态；单测 `status.test.ts`。
   - 注：连接被拒时浏览器控制台仍会打印 `ERR_CONNECTION_REFUSED`（网络栈输出，无法抑制），已用 badge/popup 消化体验。
3. **`type` 泛化 selector**：补 E2E 覆盖日志中 `type selector:"input"` 的 INTERNAL 场景（resolveInput 重写后已正常）。
4. **`plt screenshot` 无目标**：未给 `--path` 时默认落盘 `screenshot-<时间戳>.<ext>` 并打印绝对路径（`--format` 决定后缀）；`--json` 仍返回 base64 envelope。E2E `screenshot CLI`。
5. **`ping connected` 后命令 `EXTENSION_OFFLINE extension disconnected`**：根因是 `connect()` 无并发保护 + `onclose/onerror` 操作全局 `ws`，导致 alarm/心跳/重连同时建连、server 替换连接丢弃在途命令。修复：`connecting` 锁 + 每 socket 事件校验 `ws === socket` + `forceReconnect()`（配置变更/Retry 主动重连）。用临时回退对照确认 E2E 可复现/修复。
